# راهنمای فارسی MarketplaceBridge — نسخه 0.2.0-alpha

**هشدار: این نسخه هنوز Production-Ready نیست. صرفاً در محیط آزمایشی استفاده شود.**

## نصب و ارتقا

۱. ابتدا از سایت و دیتابیس نسخه پشتیبان بگیرید. ووکامرس باید فعال باشد و PHP 8.2 یا بالاتر وجود داشته باشد.
۲. ZIP افزونه را از بخش افزونه‌ها در وردپرس نصب یا جایگزین نسخه قبلی کنید.
۳. در مسیر **اتصال به بازارگاه‌ها ← اتصال‌ها** توکن‌های سرویس‌دهنده را وارد کنید. برای مشاهدهٔ رابط فارسی، زبان وردپرس یا زبان حساب مدیریتی را روی فارسی قرار دهید.
۴. واحد قیمت محصولات ووکامرس را به‌درستی انتخاب کنید: **IRR = ریال** یا **IRT = تومان**. خروجی قیمت ترب به تومان خواهد بود.
۵. برای هر فروشنده اضافه دیجی‌کالا شناسه مستقل، کد فروشنده و Access Token مجاز وارد کنید.
۶. در **نگاشت محصولات**، محصول ساده یا تنوع را با نام، SKU یا شناسه پیدا کنید و به شناسهٔ تنوع مربوط به حساب فروشندگی دیجی‌کالا نگاشت کنید. ویرایش هر نگاشت از فهرست نگاشت‌های همان حساب انجام می‌شود.
۷. در **فهرست API**، فایل JSON رسمی پنل فروشندگان را وارد کنید. فرم اجرای درخواست برای عملیات خواندنی نمایش داده می‌شود.
۸. در **ترب ← فید محصولات** قیمت تومانی و وضعیت موجودی نمونه‌ها را پیش‌نمایش کنید. سپس نشانی فید را برای راه‌اندازی به ترب بدهید. در **صف ارسال** وضعیت اعلان‌ها و خطاها را دنبال و موارد ناموفق را دوباره در صف بگذارید.

## امکانات تکمیل‌شده یا اصلاح‌شده

- API محصولات ترب با JWT و اصلاح صفحه‌بندی.
- اطلاع‌رسانی تغییرات محصول به ترب با تلاش مجدد محدود.
- عملیات انتخابی Shop API ترب و گزارش کلیک و قیمت.
- ثبت اختیاری سفارش‌ها و اقدامات ارجاعی ترب.
- نگهداری رمزنگاری‌شده توکن‌های چند حساب دیجی‌کالا.
- نگاشت دستی محصول/تنوع برای هر حساب مستقل.
- مرور امن APIهای خواندنی از فایل OpenAPI.
- اعتبارسنجی دقیق مقادیر پولی، حذف دوره‌ای سوابق و محافظت بیشتر از داده‌ها.

## موارد تکمیل‌نشده

انتشار محصول، همگام‌سازی خودکار قیمت و موجودی دیجی‌کالا، دریافت و پردازش سفارش‌های دیجی‌کالا، مدیریت ارسال و مرجوعی، امور مالی و دریافت یا تمدید خودکار توکن به پیاده‌سازی اختصاصی نیاز دارند. اتصال به APIهای زندهٔ فروشندگان نیز نیازمند آزمون با حساب مجاز است.
